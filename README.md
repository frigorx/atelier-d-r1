# Atelier D R+1 — maquette 3D

Maquette 3D interactive du réaménagement de l'atelier froid et climatisation (bâtiment D, R+1), LP Privé Jacques Raynaud — Campus ÉQUATIO.

- Cliquer un objet : affiche son nom.
- Glisser un objet : le déplacer. Bouton « Tourner » ou touche R : quart de tour.
- Chaque visiteur garde ses propres déplacements dans son navigateur.

Positions et dimensions estimées sur photos : document de travail, aucune conformité réglementaire n'est affirmée.
